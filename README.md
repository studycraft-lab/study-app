# StudyCraft

StudyCraft is a family-first study application that turns uploaded textbook pages and worksheets into traceable, interactive practice. A shared chapter question bank can be used by multiple children while preserving separate progress, mastery, and review schedules.

The first release is aimed at one family and English-medium Grade 3 and Grade 6 material. The design is grade-, subject-, and board-independent.

## Current status

Product definition and question-bank validation. Application code has not been scaffolded yet.
