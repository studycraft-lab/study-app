# Grade 6 ICSO: Fundamentals of Computers

The interactive lesson is at `/study/icso/fundamentals-of-computers`. It has six short sorting missions (23 estimated minutes) and six original final questions (about 6 minutes). The child places examples into input/process/output, hardware/software/data, software roles, application types, language levels and translation tools. This is a concept model, not a real computer or compiler. Results remain on the page and are not saved to the StudyCraft progress dashboard.

## Sources and scope

- Saved SOF synopsis: `ingestion-artifacts/icso-grade6-synopses/01-fundamentals-of-computer.html`. The lesson covers the synopsis's central categories and examples, including programming tools and machine/assembly/high-level languages.
- Recent downloaded papers: `ICSO - 2025_Class_6_2296_answer.pdf` asks statement-based questions about software and operating-system roles, plus an assembly-language identification item; `ICSO - 2024_Class_6_7530_answer.pdf` asks about a translator; `ICSO - 2023_Class_6_8757_answer.pdf` asks about CPU control and line-by-line translation. The final questions are original and use similar reasoning forms, without copying the paper text.
- Downloaded mock papers add application/utility categorisation and input-device identification. Recent papers have greater weight than older mock trivia.
- The signed-in SOF chapter question bank was not inspected for this build. Review it before claiming full exam alignment. The 29-minute duration is an estimate, not a child-tested limit.

## Accuracy decisions

| Concept | Check |
| --- | --- |
| An operating system manages hardware resources and applications | [IBM operating systems overview](https://www.ibm.com/think/topics/operating-systems) |
| Hardware is physical equipment; software supplies instructions that process data | [IBM computer hardware overview](https://www.ibm.com/think/topics/hardware) |
| High-level code needs an implementation to run | [Python execution model](https://docs.python.org/3/reference/executionmodel.html), [GCC compiler documentation](https://gcc.gnu.org/onlinedocs/gcc/Overall-Options.html) |

The synopsis's simple speed hierarchy (“machine language fastest, high-level slower”) is not taught as a universal rule. Compiled high-level code ultimately runs as machine instructions, and performance depends on the program and implementation. The compiler/interpreter distinction is presented as an introductory model, with a note that actual implementations vary. This compact lesson does not cover every operating system, utility or programming tool named in the synopsis.
