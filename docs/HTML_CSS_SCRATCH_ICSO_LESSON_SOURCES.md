# Grade 6 ICSO: HTML, CSS and Scratch lesson

The interactive lesson is at `/study/icso/html-css-scratch`. It is one compact introduction to the combined HTML, CSS and Scratch chapter, with six short missions (24 minutes in the mission estimates) and six original final questions (about 6 minutes). It uses a controlled practice workbench rather than a real HTML editor or Scratch project.

## Source coverage

- Saved SOF Grade 6 ICSO synopsis: `ingestion-artifacts/icso-grade6-synopses/07-introduction-to-html-css-and-scratch.html`. The taught core is the HTML document skeleton and title/body distinction; heading, paragraph, link, image and attributes; internal CSS; Scratch Stage, sprite, block palette and script area; and an Events → Control → Motion script. The synopsis also covers more HTML formatting tags, comments, lists, and more Scratch block categories. Those are named or left for subsequent practice because the single lesson is capped at about 30 minutes.
- `ICSO - 2025_Class_6_2296_answer.pdf` informs the question style: HTML tag functions and document order, internal CSS, Scratch controls and block categories. Older mock papers include statement-pair, tag/attribute, and category questions. The app questions are new; paper text and screenshots are not copied.
- The live SOF chapter question bank was not inspected for this lesson. Before expanding this into a full revision bank, review that bank against this lesson's scope.

## Accuracy checks

| Concept | Verification |
| --- | --- |
| `<title>` belongs in `<head>` and names the browser tab; `<body>` holds page content | [MDN title](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/title), [MDN body](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/body) |
| `<style>` supplies internal CSS, typically in `<head>` | [MDN style](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/style), [MDN CSS introduction](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Getting_started) |
| `src` supplies an image path and `alt` a text alternative | [MDN image element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img) |
| Scratch projects start with the green flag and use connected blocks | [Scratch Getting Started Guide](https://resources.scratch.mit.edu/www/guides/en/scratch-getting-started-guide.pdf) |

The planet image is a local SVG that loads from the same path shown in the code. The Scratch stage simulates a 10 × 10-step movement; it does not execute a `.sb3` program. Scores remain on the lesson page and are not saved to the StudyCraft dashboard.
