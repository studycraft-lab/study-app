# Windows 11: source review

Reviewed 8 October 2026. The local source is `ingestion-artifacts/icso-grade6-synopses/04-windows-11.html` (saved SOF Grade 6 ICSO synopsis). The six-part lesson and six-question challenge are original practice based on that outline and the style of downloaded 2023–2025 ICSO papers. The 2025 paper includes taskbar notification area and Snap Layouts. The lesson is planned for 29 minutes; the duration has not been measured with a child. The signed-in chapter question bank was not audited for this lesson.

## Product accuracy decisions

The practice desktop models interactions rather than reproducing every Windows build. Taskbar icons are centered by default and can be left-aligned. Snap Layouts are reached by the maximize button or Win + Z; Snap Assist fills the remaining space. Task View or Win + Tab is used for another desktop. Desktop background is under Settings → Personalization → Background. Widgets availability and appearance can depend on the device and configuration. Control Panel still exists; Edge is included but another default browser can be chosen.

The synopsis mentions “Tablet Mode.” Windows 11 changes its touch layout automatically on suitable devices and does not provide the old manual Tablet Mode toggle. The final challenge explicitly corrects this. The synopsis's “latest version” description is omitted because it can become dated.
