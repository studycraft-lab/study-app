## Word 2016 navigation audit (2026-10-05)

The saved synopsis calls some contextual tabs “Table Design” and “Chart Design”. Those names are useful topic labels, but they do not precisely describe the Word 2016 Windows ribbon. The practice desk now shows the 2016 contextual grouping and tab labels.

| Task | Word 2016 path or condition | Verification |
| --- | --- | --- |
| Insert a table | Insert → Tables → Table; choose the grid size | [Microsoft Press MOS Word 2016](https://www.microsoftpressstore.com/articles/article.aspx?p=2738466) |
| Table appearance | Cursor in table → Table Tools → Design; Shading is in Table Styles, Borders is in Borders | [Microsoft Press MOS Word 2016](https://www.microsoftpressstore.com/articles/article.aspx?p=2738466) |
| Repeat header rows | Select header row(s), including first row → Table Tools → Layout → Data → Repeat Header Rows | [Microsoft Press, contextual tab names](https://www.microsoftpressstore.com/articles/article.aspx?p=2738466); [Microsoft Support, selection requirement](https://support.microsoft.com/en-us/word/repeat-table-header-on-subsequent-pages) |
| Chart data | Select chart → Chart Tools → Design → Data → Edit Data | [Microsoft Support, old and new labels](https://support.microsoft.com/en-gb/excel/insert-a-chart-from-an-excel-spreadsheet-into-word) |
| Watermark | Design → Page Background → Watermark → choose a watermark | [Microsoft Support](https://support.microsoft.com/en-au/word/use-a-custom-watermark) |
| Line numbers | Layout → Page Setup → Line Numbers → Continuous | [Microsoft Support](https://support.microsoft.com/en-us/word/add-or-remove-line-numbers) |
| Proofing | Review → Proofing → Spelling & Grammar | [Microsoft Support](https://support.microsoft.com/en-us/word/training/check-grammar-spelling-and-more-in-word) |
| Zoom | View → Zoom → Zoom dialog → percentage → OK | [Microsoft Support](https://support.microsoft.com/en-us/office/video-zoom-in-or-out-64e5c8c4-1a93-4766-88fc-88086dc90a74) |
| File management | File opens Backstage view, which includes Save and Print | [Microsoft Support, Office 2016–2019](https://support.microsoft.com/en-us/office/collab-files/start-backstage-with-the-file-tab) |

Microsoft distinguishes the newer **Table Design** and **Table Layout** wording from the older **Table Tools → Design/Layout** wording: [Apply a table style](https://support.microsoft.com/en-gb/office/video-apply-a-table-style-f1b798e7-fa25-496c-a434-0c2a15bed09f). The practice desk shows a single representative choice in each insertion gallery or dialog, rather than every option in Word. The named tab, group, and command paths above are the teaching targets.
